# Vendored Time-Series-Library subset

This directory contains the `iTransformer` and `TimesNet` model
architectures from the Time-Series-Library (TSLib), together with the
specific layers and utilities those two models depend on.  Files are
taken verbatim from the upstream release; unused classes have been
removed for clarity.

Upstream project: Time-Series-Library by THUML @ Tsinghua University.
